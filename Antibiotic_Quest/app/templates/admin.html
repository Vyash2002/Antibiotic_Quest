Check each question against its cited fact, then approve it, mark it for editing, or reject it. To change wording, export the question bank (Data tab), edit the CSV, save it as data/AMR_Question_Bank.csv and run python db/init_db.py --reload-questions.

Ask Gemini to draft new questions from the verified facts for one level. Drafts that pass the automatic checks are added as pending review; they appear in the game only after someone approves them.
